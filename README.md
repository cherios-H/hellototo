# VersionamientoDeSoftware

Proyecto desarrollado en Java para la materia de *Fundamentos de Programación (CESUN)* con el objetivo de aplicar control de versiones mediante Git y GitHub.

## Estructura del proyecto
* src/Principal.java: Clase principal que ejecuta el flujo del programa.
* src/Funciones.java: Módulo auxiliar con métodos de saludo y operaciones básicas.

## Instrucciones de ejecución
1. Clonar el repositorio o descargar los archivos fuente.
2. Abrir la carpeta del proyecto en Visual Studio Code o Apache NetBeans.
3. Compilar y ejecutar la clase Principal.java.
